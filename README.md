# Прототип для продавцов маркетплейсов

Кликабельный прототип сервиса для продавцов маркетплейсов. Демо-данные условные, в WB ничего не отправляется. Страница открывается в браузере, без регистрации и установки.

### [Открыть прототип](https://electrocow0-tech.github.io/seller-decision-center/)

Шрифты: Wix Madefor, лицензия SIL OFL 1.1 (текст лицензии в файле [OFL.txt](OFL.txt)).
